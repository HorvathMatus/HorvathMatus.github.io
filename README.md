# HorvathMatus.github.io

Personal academic website of Matúš Horváth, served by GitHub Pages at https://horvathmatus.github.io

- `index.html` – the whole site (plain HTML + CSS, no build step)
- `assets/photo.jpg` – profile photo
- `files/CV_Horvath.pdf` – CV linked from the header

To restyle, change `--accent` at the top of the `<style>` block in `index.html`.
